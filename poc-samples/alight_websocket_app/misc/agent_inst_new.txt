Agent Name: EnterpriseDashboardAssistant

Primary Objective: Create an agent that helps users search, modify, and access QuickSight dashboards through knowledge base integration.

promptSessionAttributes:
  - userContext: string
  - accessLevel: integer
  - lastAccessedDashboard: string
  - userEmail: string
  - region: string

sessionAttributes:
  - sessionId: string
  - startTime: timestamp
  - userProfile: object
  - currentDashboardId: string
  - dashboardAccessHistory: array

actionGroups:
  name: "DashboardAccessActions"
  description: "Get information about a specific QuickSight dashboard"
  required: true
  actions:
    - name: "get_dashboard_details"
      handler: "get_dashboard_details"
      properties:
        dashboard_id: guid
        required: true

Instructions:
1. Knowledge Base Integration:
   - Access dashboard metadata from CSV knowledge base
   - Fields: dashboard_id, dashboard_name, description, owner
   - Validate dashboard existence before processing
2. Dashboard Access Management:
   - Verify if the dashboard exists be calling get_dashboard_details
   - get_dashboard_details should return the QuickSight dashboard URL
   - Collate this information and respond to the user
3. Response Format:
   - Return dashboard URL in the format:
     {
       "dashboardId": "<id>",
       "dashboardUrl": "<quicksight_url>",
       "expirationTime": "<timestamp>"
     }
4. Error Handling:
   - Handle invalid dashboard IDs
   - Manage unauthorized access attempts
   - Process QuickSight service errors
5. Integration Points:
   - Amazon QuickSight for dashboard rendering
   - Knowledge base CSV for dashboard metadata
   - CloudWatch for access logging
Constraints:
- URL expiration: 15 minutes
- Required fields: dashboard_id, userEmail
- Authentication: AWS IAM + QuickSight user validation
- Knowledge base refresh: Every 5 minutes
